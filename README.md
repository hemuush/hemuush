```mermaid

    U([User]) --> API[FastAPI service]
    API --> AG{Agent / LangGraph}
    AG -->|retrieve| R[(Azure AI Search<br/>ChromaDB)]
    AG -->|tools| M[MCP servers<br/>internal APIs]
    R --> LLM[Azure OpenAI / LLM]
    M --> LLM
    LLM --> EV[Output evaluation]
    EV --> U
```
